# Plano de 10 commits reais

Execute os commits gradualmente, após cada alteração correspondente (não declare commits que não existam):

1. `docs: definir escopo inicial do projeto`
2. `chore: criar estrutura de pastas`
3. `docs: documentar requisitos e execução`
4. `feat: configurar aplicação Flask`
5. `feat: criar persistência SQLite`
6. `feat: implementar cadastro e listagem de tarefas`
7. `feat: permitir edição e exclusão de tarefas`
8. `test: adicionar testes de validação e CRUD`
9. `ci: configurar testes e lint no GitHub Actions`
10. `feat: adicionar filtro de tarefas por status`

**Atenção:** subir tudo em um único commit não satisfaz o requisito de 10 commits distribuídos pelo desenvolvimento. O arquivo descreve um plano, não um histórico já executado.
