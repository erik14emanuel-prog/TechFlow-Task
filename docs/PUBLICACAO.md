# Checklist de publicação e evidências

1. Crie um repositório **público** no GitHub e publique o código.
2. Crie um GitHub Project e adicione os 12 cards do `BACKLOG.md`, usando To Do, In Progress e Done.
3. Registre **10 commits reais**, progressivos, com as mensagens de `COMMITS.md` (adapte a sequência ao desenvolvimento efetivo).
4. Confira na aba Actions que o workflow executou testes e Ruff com sucesso.
5. Tire capturas reais do Kanban, histórico de commits e workflow verde. Insira no relatório nos espaços indicados.
6. Grave o vídeo pitch (até 4 minutos), publique no YouTube ou Drive com link público e inclua esse link na entrega.
7. Substitua no relatório os campos de aluno, turma, links e evidências.

Não invente prints, links, commits ou resultados do GitHub.
